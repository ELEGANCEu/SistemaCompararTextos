Comparador de Textos por Similaridade

Sobre o projeto

Este site foi desenvolvido para projeto de final de curso, Engenharia de Software, pela Uninter. Um simples comparador textual que auxilia na análise de semelhanças entre conteúdos escritos.permitindo comparar dois textos ou analisar vários textos de uma vez, com barras e indicadores que facilitam a experiência do usuário.


Nenhum dado será coletado aqui!

Como funciona?

O site processa os textos e calcula diferentes medidas de similaridade. Comparando dois ou mais textos, os resultados são combinados em uma pontuação geral. Na comparação múltipla, o usuário pode visualizar uma matriz e um ranking dos pares mais semelhantes.

Métodos utilizados

  • TF-IDF e Cosseno: Calcula a importância de uma palavra em um texto e usa similaridade para comparação.
  • Jaccard: Calcula a similaridade entre dois ou mais conjuntos de dados.
  • Bigramas: Compara pares de palavras, considerando parte da ordem do texto.

Opções de análise

Antes de comparar, o usuário pode escolher se deseja remover palavras comuns, reduzir em formas simplificadas e ignorar diferenças de acentuação. Essas opções alteram a forma em que o texto é processado.

Tecnologias

O site foi desenvolvido de maneira tradicional, apenas com o auxilio do Python para auxiliar no processamento e comparação textual

Python HTML CSS JavaScript
Importante: Apesar de uma pontuação alta indicar grande semelhança, não comprova plágio nem determina a origem de um texto. Os resultados devem ser interpretados considerando o contexto e uma análise humana.
